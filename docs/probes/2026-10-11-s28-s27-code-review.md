## Cleared — checked, nothing found

- **D-043, `repaired_answer` and the hold (`chat.py`).**
  - *Order against the leak path:* the first draft and the re-ask both feed
    the scanner chunk by chunk. A trip in either returns before anything held
    is yielded, and `scanner.result()` turns it into LEAK_COPY with
    `output_valid: false`. The held draft is never sent.
  - *Usage:* the re-ask is claimed before it is made. A refusal from the
    ceiling means no call and the code answer. The usage dict adds the
    re-ask's usage with `_add_usage`.
  - *Two-pass and thinks-natively:* `hold` gates the content `yield` in
    `native_answer` and in pass 2. The repair runs after either, and only if
    the scanner has not tripped.
  - *A `None` code answer cannot be joined:* `CODE_DECIDED_MODES` is exactly
    {alert_triage, phishing_analysis}. Both set `code_answer`, and `hold`
    requires one of them.
  - *A stale `finish_reason` on a code-rendered answer* (the first attempt's
    `length`) is harmless: the page never reads it.
  - *The repair directive's index:* it is indexed from an empty-draft
    rendering. The live directive differs only in the clause after "because".
    The 12 fixed words before that clause cover it at the content floor of 8.
    The whole directive is about 44 words, so the thinking floor of 40 never
    sees a full recital. That is D-040's design: thinking may quote.
