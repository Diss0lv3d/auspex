# Probe: CISA KEV JSON feed (S7 ingestion)

- **Date:** 2026-07-17
- **Target:** `https://www.cisa.gov/sites/default/files/feeds/known_exploited_vulnerabilities.json`
  (public, keyless, single static file — no pagination, no query params)
- **Why:** KEV supplies the known-exploited flag + ransomware use for S7's
  enriched CVE docs; new-KEV-entry is the future retro-hunt trigger (S14).

## Measured

- GET → HTTP 200, **1 552 342 bytes** plain / **177 805 bytes** with
  `--compressed` (gzip, 8.7×). Fetch gzip'd, always.
- Headers: `last-modified: Thu, 16 Jul 2026 17:00:15 GMT`,
  `etag: "17afd6-656bd5fc47c40"`, `cache-control: max-age=2236`.
- **Conditional GET: `If-Modified-Since` works (→ 304, 0 bytes).
  `If-None-Match` does NOT** — replaying the exact etag returned 200 + full
  body (etag varies by content-encoding at their CDN). Cache on
  Last-Modified, ignore ETag.
- Update cadence: `catalogVersion: "2026.07.16"` == dateReleased day;
  newest `dateAdded` = 2026-07-16 (yesterday). Effectively business-daily
  batches; `max-age` ≈ 37 min. Daily re-check is plenty.

## Shape

```
{ title, catalogVersion: "2026.07.16",
  dateReleased: "2026-07-16T17:00:15.6845Z",
  count: 1647,                      ← == len(vulnerabilities)
  vulnerabilities: [ {
    cveID: "CVE-2021-44228",
    vendorProject: "Apache", product: "Log4j2",
    vulnerabilityName: "Apache Log4j2 Remote Code Execution Vulnerability",
    dateAdded: "2021-12-10",        ← "KEV since" for the echo
    shortDescription: "...",        ← plain prose, ~1-2 sentences
    requiredAction: "...",          ← can be a full paragraph (BOD 26-04 text)
    dueDate: "2021-12-24",
    knownRansomwareCampaignUse: "Known" | "Unknown",   ← ONLY these 2 values
    notes: "url ; url ; ...",       ← semicolon-separated URLs, may be ""
    cwes: ["CWE-502", ...]          ← may be []
  }, ... ] }
```

Every entry carried all 11 keys (union == every-entry set, 1647 entries);
`dateAdded` range 2021-11-03 → 2026-07-16.

## What our code must therefore do

- One cached fetch per ingest cycle: send `If-Modified-Since` from the
  stored watermark; 304 ⇒ done, zero parse. Store `Last-Modified` +
  `catalogVersion` in ingest_state.
- Index by `cveID` into a dict once per cycle; enrich CVE docs via O(1)
  lookup (1 647 entries, trivially in-memory).
- `knownRansomwareCampaignUse == "Known"` is the ONLY truthy ransomware
  signal; "Unknown" must render as absence-of-evidence, never "no".
- KEV echo fields: dateAdded ("known exploited — KEV since 2021-12-10"),
  ransomware flag; dueDate/requiredAction are federal-agency directives —
  out of echo scope (parked).
