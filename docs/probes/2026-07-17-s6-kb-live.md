## Two real bugs caught BY this live verify (fixed + regression-pinned)

1. **Missing absolute neural floor** (caught pre-turn, while planning the
   matrix): kNN returns k neighbors for ANY query — an off-corpus question
   would have fused pure noise into a "KB answer". Fix: 0.6 pre-fusion floor
   on the bounded [0,1] neural scores (probed relevant 0.695 vs unrelated
   0.498). Commit `b0a026a`.
2. **BM25 stopword/fuzzy leak** (caught live): even WITH the neural floor,
   `what is quantum entanglement` answered with the C2 doc — BM25
   `multi_match` scored it 4.4 via "what"/"is" + fuzziness, and relative
   floors cannot detect an all-garbage result set. Leg-level measurements:
   neural top 0.586 (below floor, correctly dead), BM25 4.405 (noise).
   Fix: post-floor-empty neural leg = relevance gate ⇒ honest miss
   (BM25-only is reserved for neural *unavailability*, not *disagreement*);
   ID-rail misses stop falling back to fuzzy prose;
   `minimum_should_match: 2<75%` damping. Commit `7446fbc` — retested live:
   both former fabrications now return the miss copy, relevant queries
   unaffected.
