# 2026-10-28 — B4: B-025 before the fix (a sign-in racing a rehome)

Reproduced on `b4-bugs` (`d78bc43`) with S31's script
`docs/probes/s31-b025/race_enter.py`, run from a scratch copy whose paths
point at this clone (the script names Burhan's checkout). Synthetic orgs only,
deleted afterwards:

```
entered: t-s31-b021rev-client1
client1's trail, newest: workspace.enter actor.organization = t-s31-b021rev-othercustomer
cleanup, orgs left: 0
```

The cause: `enter()` (`auspex/tenancy/entry.py:16-29`) decides access in one
query and reads `users.home_org_id` in another, each on its own pool
connection with no lock. A membership removal plus `rehome_person` between them
puts the NEW home's name on an event in the OLD home's workspace, which that
organization's admins read through `GET /api/audit`.

## After the fix

`enter()` now runs in one transaction that locks the person's `users` row
`FOR SHARE` before deciding access, and records the event on the same
connection. `rehome_person` locks that row `FOR NO KEY UPDATE`, so a rehome
waits for an entry in flight. The regression test
`test_a_rehome_racing_a_sign_in_never_names_the_new_home_in_the_old_trail`
(tests/test_tenancy_entry.py) forces the interleaving: it starts the removal
and rehome between the access decision and the event, and gives it 0.5 s to
land. Before the fix it failed with
`'t-s30-entry-b025-other' == 't-s30-entry-b025-client'`; after, it passes, and
all 138 tenancy and auth tests pass. The S31 script can no longer interpose:
the separate `home_org` read it wrapped is gone.

## Review, and the switch path

The fresh adversarial review approved the fix (no deadlock cycle; NoAccess
leaves no row; one connection per entry). On its note, the switch path got its
own race test,
`test_a_rehome_racing_a_switch_never_names_the_new_home_in_the_old_trail`.
Run against the pre-fix `entry.py` (restored after), both race tests failed;
against the fix, both pass. The review's other finding, the membership API
stamping a home read before its write, is logged as B-034.
