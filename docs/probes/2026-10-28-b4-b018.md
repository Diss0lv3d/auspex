# 2026-10-28 — B4: B-018 before the fix (a URL keeps its credentials)

Reproduced in the running app container (`staging` at `cc85b0e`), with
placeholder credentials only:

```
$ docker compose exec -T app python -c "from auspex.classify.observables import extract; ..."
[('url', 'http://analyst:PLACEHOLDER-PW@evil.example.com/drop.exe')]
[('url', 'https://bob@phish.example.com:8443/login?x=1')]
```

The cause: `_normalize_url` (`auspex/classify/observables.py:269-282`)
lowercases the host and keeps the userinfo (`user:pass@`). The observable's
`value` is what is looked up at URLhaus and upserted into `observables`, so
the credential travels to a third party and into storage. `residual` blanks the
whole URL span, and `Observable` carries no raw text, so `value` is the only
carrier.
