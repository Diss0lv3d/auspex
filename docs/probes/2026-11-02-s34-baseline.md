  (`auspex/routes/proposals.py:331` and siblings): any analyst or admin of the active
  workspace, provider staff included once they switched in. No per-risk rule.

## How an action is found by name
- One app-wide `ActionRegistry` of built-ins (`auspex/app.py:79-80`;
  `auspex/actions/registry.py:136` `get(name)`), looked up at:
  settlement `:711`, `:775`, `:998`; `auspex/routes/proposals.py:383`; the agent loop
  (`auspex/agent/loop.py:842` `_action_spec`) and `routes/chat.py:920` (the tools
  offered). Not workspace-aware: connector actions need a resolver by workspace.
- `EXECUTABLE_SYSTEMS = frozenset({"auspex"})` — `settlement.py:52`;
  `check_executable` `:652`, `check_fingerprint` `:592` (execute only since D-074;
  its docstring still names undo), `check_undo_identity` `:632`.
