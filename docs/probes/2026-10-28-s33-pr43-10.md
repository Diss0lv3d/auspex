Before (`s33-edge-agent` at `23bbf6b`):


The build wrote its own version into `manifest.json`, which the content hash
covers, so the same source built by another SDK version was "other content",
and registering it under the same version answered "bump the version".

**Decided (Hunaiza, S33): the SDK version is not part of a package's identity**
(D-072). The build records it in the zip's own comment
(`auspex-sdk <version>`), which the hash never covered; `manifest.json` keeps
the optional field, empty.
