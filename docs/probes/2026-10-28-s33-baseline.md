# 2026-10-28 — S33 baseline: what the Edge Agent and integrations build on

Read on `s33-edge-agent` after the PR #43 review fixes (`f87acd7`). Code is
the authority; these are `file:line` anchors, not a design.

## Connector actions (S32, as fixed at S33 Step 0)

- `compile_action` — `auspex/connectors/compile.py:126`. Takes `manifest`,
  `action`, `content_hash`, `prefix`, `integration_id`, **`workspace_id`** (the
  integration's; every role refuses any other, `WorkspaceMismatch` `:107`,
  PR #43 #2) and `dispatch`.
- `Dispatch` protocol — `compile.py:50`: `await dispatch(kind, payload)`; it
  returns the SDK envelope (dry_run/execute/undo) or an int (observe).
- Job kinds — `_KIND` `compile.py:47` from `CONNECTOR_KINDS`
  (`auspex/connectors/jobs.py`): `connector.test`, `connector.fetch`,
  `connector.action.{dry_run,execute,undo,observe}`.
- `ConnectorJobPayload` — `jobs.py:25`: `integration_id`, `content_hash`,
  `command`, `action`, `arguments`, `proposal_id`, `idempotency_key`,
  `cursor`, `limit`. The workspace is the job row's, not the payload's.
- Results — `_outcome` `compile.py:70` (envelope → `ActionOutcome`, text
  flattened), `_count` `:112` (observe).

## Approvals

- `EXECUTABLE_SYSTEMS = frozenset({"auspex"})` — `auspex/actions/settlement.py:52`.
  A compiled connector spec's scope system is the manifest id, so today
  `check_executable` (`:630`) refuses it as `system_not_executable`.
- `check_fingerprint` — `settlement.py:591`, now shared by execute and undo
  (PR #43 #5). `integration_id` is not in the fingerprint; `ConnectorOrigin`
  carries `connector_id` and `content_hash` (`auspex/actions/types.py`).
- Execute paths — `execute` `:681`, `run_stale_approval` `:720`,
  `_run_claimed` `:798`; undo `:924`.

## Catalogue

- `register` — `auspex/connectors/catalogue.py:87`; `available` — `:233`
  (one source per id: first-party > provider > own).
- Package bytes are stored in `connector_packages.package` (TD-066), keyed by
  `(workspace_id, content_hash)`.

## Jobs queue (S31)

- `JobKind` — `auspex/jobs/queue.py:31` (`lease_seconds` default 60,
  `max_attempts` 5). `Job` — `:51` carries `integration_id`.
- `ClaimScope` — `queue.py:159`: `kinds`, `workspace_ids` (None = all),
  `integration_ids` (None = only jobs bound to no integration; a set = only
  those). The Edge Agent passes its workspace and its integrations.
- `claim` — `:179`; `complete` — `:246`; `fail` — `:262`. No lease extension
  (TD-064): S33's heartbeats are where it belongs.
- `jobs.integration_id` — `auspex/migrations.py:812`, no FK yet (S31 waited
  for S33's table).
