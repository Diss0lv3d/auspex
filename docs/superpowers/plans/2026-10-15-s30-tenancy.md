# S30 MSSP Tenancy Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build D-061's tenancy: organizations, each provider's own workspace,
one user per person, memberships with roles and the provider-wide grant, one
workspace per token with an audited switch, enforced roles, and a region guard
over the engine and third-party enrichment.

**Architecture:** A new package `auspex/tenancy/` holds the model's rules once:
- `region.py`: the residency rule;
- `access.py`: `enterable_workspaces`, the only answer to "may this person
  enter, and as what";
- `audit.py`: the append-only trail;
- `admin.py`: every write;
- `entry.py`: the one way into a workspace;
- `__main__.py`: the CLI.

`auspex/auth.py`'s `resolve_user` re-checks access on every request through
`access.py`, and `require_role` builds three dependency aliases. Schema changes
are appended to the idempotent `SCHEMA_V0` list, with a one-time guarded `DO`
block that migrates `users` from "a row per workspace" to "a person plus
memberships".

**Tech Stack:** FastAPI 0.139 (routes are walked with
`fastapi.routing.iter_route_contexts`), asyncpg, Postgres 16, pytest with
`asyncio_mode = "auto"`, pydantic-settings.

**Spec:** docs/superpowers/specs/2026-10-15-s30-tenancy-design.md (the S30
design; read it first). It sits on D-061 and the phase spec
docs/superpowers/specs/2026-10-15-integration-phase-design.md. Reality it
stands on: docs/probes/2026-10-15-s30-tenancy-baseline.md.

  organization id from a request body, header or query string, except

"""Residency as a refusal (D-061; S30 design §4).

Each workspace carries a region; the deployment's engine processes in one
(`ENGINE_REGION`), and each enrichment provider declares its own in code. A
`global` workspace carries no residency constraint, so anything may serve it;
any other region is served only from inside itself. Stdlib only: `auspex.config`
imports this module.
"""

GLOBAL = "global"
# A new region is a code change, reviewed, never a row someone inserts. The
# workspaces.region CHECK (auspex/migrations.py) holds the same list, and a
# test pins that the two agree.
REGIONS: frozenset[str] = frozenset({GLOBAL, "ksa"})


def check_region(region: str) -> str:
    if region not in REGIONS:
        raise ValueError(f"unknown region {region!r}; known regions: {', '.join(sorted(REGIONS))}")
    return region


def may_process(workspace_region: str, processor_region: str) -> bool:
    """Whether a processor in `processor_region` may handle the data of a
    workspace in `workspace_region`. An unknown region is an error, never a yes."""
    check_region(workspace_region)
    check_region(processor_region)
    return workspace_region == GLOBAL or workspace_region == processor_region


def engine_refusal(workspace_region: str, engine_region: str) -> str | None:
    """The reason an engine turn is refused, or None when the engine may serve it."""
    if may_process(workspace_region, engine_region):
        return None
    return (
        f"This workspace's data must stay in region {workspace_region}, and the "
        f"platform's engine here processes in region {engine_region}, so it cannot "
        "run this request. Answers that need no engine still work."
    )


def region_skip(region: str) -> str:
    """The skip reason an indicator carries when no allowed source exists."""
    return (
        "not looked up: every connected source processes outside this "
        f"workspace's region ({region})"
    )


def lookup_refusal(region: str) -> str:
    return (
        "Third-party lookups are not available in this workspace's region "
        f"({region}): every connected source processes outside it."
    )
```

"""Test plumbing for S30's tenancy (D-061). Raw SQL on purpose: a test must be
able to write a row the rules in auspex/tenancy/admin.py would refuse, to prove
the READ side still grants nothing for it."""

from dataclasses import dataclass
from uuid import UUID

from auspex.auth import issue_jwt


async def make_org(db, name: str, kind: str, *, parent: UUID | None = None,
                   restricted: bool = False) -> UUID:
    return await db.fetchval(
        "INSERT INTO organizations (name, kind, parent_id, restricted)"
        " VALUES ($1, $2, $3, $4) RETURNING id",
        name, kind, parent, restricted,
    )


async def make_workspace(db, name: str, org_id: UUID, *, region: str = "global") -> UUID:
    return await db.fetchval(
        "INSERT INTO workspaces (name, org_id, region) VALUES ($1, $2, $3) RETURNING id",
        name, org_id, region,
    )


async def make_user(db, email: str, home_org_id: UUID) -> UUID:
    return await db.fetchval(
        "INSERT INTO users (email, home_org_id) VALUES ($1, $2) RETURNING id",
        email, home_org_id,
    )


async def add_membership(db, workspace_id: UUID, user_id: UUID, role: str, *,
                         provider_wide: bool = False) -> None:
    await db.execute(
        "INSERT INTO memberships (workspace_id, user_id, role, provider_wide)"
        " VALUES ($1, $2, $3, $4)",
        workspace_id, user_id, role, provider_wide,
    )


async def ensure_workspace(db, name: str, *, region: str = "global") -> UUID:
    """A test workspace with its own direct organization, get-or-create: the
    shape of the `INSERT INTO workspaces … ON CONFLICT` lines it replaces (S30:
    a workspace belongs to an organization)."""
    org_id = await db.fetchval(
        "INSERT INTO organizations (name, kind) VALUES ($1, 'direct')"
        " ON CONFLICT (name) DO UPDATE SET name = EXCLUDED.name RETURNING id",
        name,
    )
    return await db.fetchval(
        "INSERT INTO workspaces (name, org_id, region) VALUES ($1, $2, $3)"
        " ON CONFLICT (name) DO UPDATE SET name = EXCLUDED.name RETURNING id",
        name, org_id, region,
    )


async def ensure_member(db, workspace_id: UUID, email: str, *, role: str = "analyst",
                        display_name: str = "") -> UUID:
    """The person with this email, homed in the workspace's organization when
    new, with a membership there: what `INSERT INTO users (workspace_id, email)`
    meant before S30."""
    org_id = await db.fetchval("SELECT org_id FROM workspaces WHERE id = $1", workspace_id)
    user_id = await db.fetchval(
        "INSERT INTO users (email, display_name, home_org_id) VALUES ($1, $2, $3)"
        " ON CONFLICT ((lower(email))) DO UPDATE SET display_name = EXCLUDED.display_name"
        " RETURNING id",
        email, display_name, org_id,
    )
    await db.execute(
        "INSERT INTO memberships (workspace_id, user_id, role) VALUES ($1, $2, $3)"
        " ON CONFLICT (workspace_id, user_id) DO UPDATE SET role = EXCLUDED.role",
        workspace_id, user_id, role,
    )
    return user_id


async def drop_orgs(db, prefix: str) -> None:
    """Delete every organization named `prefix…`, with its workspaces and the
    people homed in it. Clients go before providers (parent_id is RESTRICT)."""
    org_ids = [
        r["id"] for r in await db.fetch(
            "SELECT id FROM organizations WHERE starts_with(name, $1)", prefix
        )
    ]
    if not org_ids:
        return
    await db.execute("DELETE FROM workspaces WHERE org_id = ANY($1::uuid[])", org_ids)
    await db.execute("DELETE FROM users WHERE home_org_id = ANY($1::uuid[])", org_ids)
    await db.execute(
        "DELETE FROM organizations WHERE id = ANY($1::uuid[]) AND kind = 'client'", org_ids
    )
    await db.execute("DELETE FROM organizations WHERE id = ANY($1::uuid[])", org_ids)


@dataclass(frozen=True)
class Mssp:
    """One provider with two clients (client2 restricted) and one direct
    customer — the shape every S30 cross-tenant test reasons about."""

    provider: UUID
    provider_ws: UUID
    client1: UUID
    client1_ws: UUID
    client2: UUID
    client2_ws: UUID
    direct: UUID
    direct_ws: UUID
    p_admin: UUID  # home provider; admin in provider_ws, provider_wide
    p_analyst: UUID  # home provider; analyst in provider_ws, no grant
    c1_user: UUID  # home client1; analyst in client1_ws
    c2_user: UUID  # home client2; analyst in client2_ws
    d_user: UUID  # home direct; admin in direct_ws


async def build_mssp(db, prefix: str) -> Mssp:
    provider = await make_org(db, f"{prefix}-provider", "provider")
    client1 = await make_org(db, f"{prefix}-client1", "client", parent=provider)
    client2 = await make_org(db, f"{prefix}-client2", "client", parent=provider,
                             restricted=True)
    direct = await make_org(db, f"{prefix}-direct", "direct")
    provider_ws = await make_workspace(db, f"{prefix}-provider", provider)
    client1_ws = await make_workspace(db, f"{prefix}-client1", client1)
    client2_ws = await make_workspace(db, f"{prefix}-client2", client2)
    direct_ws = await make_workspace(db, f"{prefix}-direct", direct)
    domain = f"{prefix}.auspex.dev"
    p_admin = await make_user(db, f"p-admin@{domain}", provider)
    p_analyst = await make_user(db, f"p-analyst@{domain}", provider)
    c1_user = await make_user(db, f"c1-user@{domain}", client1)
    c2_user = await make_user(db, f"c2-user@{domain}", client2)
    d_user = await make_user(db, f"d-user@{domain}", direct)
    await add_membership(db, provider_ws, p_admin, "admin", provider_wide=True)
    await add_membership(db, provider_ws, p_analyst, "analyst")
    await add_membership(db, client1_ws, c1_user, "analyst")
    await add_membership(db, client2_ws, c2_user, "analyst")
    await add_membership(db, direct_ws, d_user, "admin")
    return Mssp(provider, provider_ws, client1, client1_ws, client2, client2_ws,
                direct, direct_ws, p_admin, p_analyst, c1_user, c2_user, d_user)


def token(settings, user_id: UUID, workspace_id: UUID) -> dict:
    return {"Authorization": f"Bearer {issue_jwt(settings, user_id, workspace_id)}"}
```

"""Who may enter which workspace, and as what (D-061; S30 design §2).

`enterable_workspaces` is ONE statement and the only code that answers it:
token mints, every request's re-check (auspex/auth.py) and every cross-client
view go through it. Its two parts:

- an explicit membership counts only where the workspace's organization is the
  person's home organization or a client of it. The write path refuses
  anything else (auspex/tenancy/admin.py); this side re-checks, so a stray row
  grants nothing;
- a `provider_wide` membership on a workspace of the person's own PROVIDER
  home organization reaches every workspace of that provider's clients that
  are not `restricted`.

An explicit membership's role wins over a grant on the same workspace (the more
specific statement). `__deployment__` has no organization, so nothing reaches it.
"""

from dataclasses import dataclass
from uuid import UUID

ROLES = ("admin", "analyst", "viewer")


@dataclass(frozen=True)
class Access:
    workspace_id: UUID
    workspace_name: str
    region: str
    org_id: UUID
    org_name: str
    org_kind: str
    role: str
    via: str  # "membership" | "provider_wide"


_ENTERABLE_SQL = """
WITH me AS (
    SELECT home_org_id FROM users WHERE id = $1
),
reach AS (
    SELECT o.id FROM organizations o, me
     WHERE o.id = me.home_org_id OR o.parent_id = me.home_org_id
),
explicit AS (
    SELECT m.workspace_id, m.role, 'membership'::text AS via
      FROM memberships m
      JOIN workspaces w ON w.id = m.workspace_id
     WHERE m.user_id = $1
       AND w.org_id IN (SELECT id FROM reach)
),
granted AS (
    SELECT cw.id AS workspace_id, m.role, 'provider_wide'::text AS via
      FROM memberships m
      JOIN me ON true
      JOIN workspaces pw ON pw.id = m.workspace_id
      JOIN organizations po ON po.id = pw.org_id
      JOIN organizations co ON co.parent_id = po.id
      JOIN workspaces cw ON cw.org_id = co.id
     WHERE m.user_id = $1
       AND m.provider_wide
       AND po.kind = 'provider'
       AND po.id = me.home_org_id
       AND co.kind = 'client'
       AND NOT co.restricted
),
everything AS (
    SELECT * FROM explicit
    UNION ALL
    SELECT * FROM granted
)
SELECT DISTINCT ON (e.workspace_id)
       e.workspace_id, e.role, e.via,
       w.name AS workspace_name, w.region,
       o.id AS org_id, o.name AS org_name, o.kind AS org_kind
  FROM everything e
  JOIN workspaces w ON w.id = e.workspace_id
  JOIN organizations o ON o.id = w.org_id
 WHERE $2::uuid IS NULL OR e.workspace_id = $2::uuid
 ORDER BY e.workspace_id,
          (e.via = 'membership') DESC,
          CASE e.role WHEN 'admin' THEN 3 WHEN 'analyst' THEN 2 ELSE 1 END DESC
"""


async def enterable_workspaces(db, user_id: UUID, *, only: UUID | None = None) -> dict[UUID, Access]:
    rows = await db.fetch(_ENTERABLE_SQL, user_id, only)
    return {
        r["workspace_id"]: Access(
            workspace_id=r["workspace_id"],
            workspace_name=r["workspace_name"],
            region=r["region"],
            org_id=r["org_id"],
            org_name=r["org_name"],
            org_kind=r["org_kind"],
            role=r["role"],
            via=r["via"],
        )
        for r in rows
    }


async def home_org(db, user_id: UUID) -> UUID | None:
    return await db.fetchval("SELECT home_org_id FROM users WHERE id = $1", user_id)


async def user_by_email(db, email: str) -> UUID | None:
    return await db.fetchval(
        "SELECT id FROM users WHERE lower(email) = lower($1)", email.strip()
    )


async def landing(db, user_id: UUID) -> Access | None:
    """Where a sign-in lands: the home organization's workspaces first, then the
    rest, each group by name. None when the person may enter nothing."""
    home = await home_org(db, user_id)
    if home is None:
        return None
    reachable = sorted(
        (await enterable_workspaces(db, user_id)).values(),
        key=lambda a: (a.org_id != home, a.workspace_name),
    )
    return reachable[0] if reachable else None

The CLI, the membership API and the tests all come through here, so the rules
live once: a membership's workspace belongs to the person's home organization
or to a client of it; `provider_wide` only on a provider's own workspace;
nobody changes their own membership. Each write records its audit event in the
same transaction as the change.
"""

from uuid import UUID

import asyncpg

from auspex.llm.scorecard import DEPLOYMENT_WORKSPACE


class TenancyError(ValueError):
    """A refused tenancy write. `status` is the HTTP status the API answers with."""

    status = 400


class NotFound(TenancyError):
    status = 404


class Conflict(TenancyError):
    status = 409


class Refused(TenancyError):
    status = 403


class Invalid(TenancyError):
    status = 422


def _clean_email(email: str) -> str:
    cleaned = email.strip()
    local, at, domain = cleaned.partition("@")
    if not at or not local or not domain or any(c.isspace() for c in cleaned):
        raise Invalid("Not an email address")
    return cleaned


async def _ensure_direct_workspace(conn: asyncpg.Connection, name: str) -> tuple[UUID, UUID]:
    """(org_id, workspace_id) of the workspace `name`, made with its own direct
    organization when absent. Dev provisioning only."""
    row = await conn.fetchrow("SELECT id, org_id FROM workspaces WHERE name = $1", name)
    if row is not None:
        return row["org_id"], row["id"]
    org = await conn.fetchrow(
        "INSERT INTO organizations (name, kind) VALUES ($1, 'direct')"
        " ON CONFLICT (name) DO UPDATE SET name = EXCLUDED.name RETURNING id, kind",
        name,
    )
    if org["kind"] != "direct":
        raise Conflict(f"An organization named {name!r} exists and is not a direct customer")
    workspace_id = await conn.fetchval(
        "INSERT INTO workspaces (name, org_id) VALUES ($1, $2)"
        " ON CONFLICT (name) DO UPDATE SET name = EXCLUDED.name RETURNING id",
        name, org["id"],
    )
    return org["id"], workspace_id


async def provision_dev_user(
    pool: asyncpg.Pool, email: str, display_name: str = "", workspace_name: str = "default"
) -> UUID:
    """The person with this email; a new one (dev login only, S30 call 2) is homed
    in `workspace_name`'s organization with an analyst membership there. An
    existing person gains nothing: they enter what they already may."""
    if workspace_name == DEPLOYMENT_WORKSPACE:
        # D-035: a user inside the deployment's system workspace could read, and
        # a later writer could poison, what every tenant's turn is compiled from.
        raise Refused(f"{DEPLOYMENT_WORKSPACE!r} is reserved for the deployment")
    email = _clean_email(email)
    async with pool.acquire() as conn, conn.transaction():
        existing = await conn.fetchval(
            "SELECT id FROM users WHERE lower(email) = lower($1)", email
        )
        if existing is not None:
            if display_name:
                await conn.execute(
                    "UPDATE users SET display_name = $2 WHERE id = $1", existing, display_name
                )
            return existing
        org_id, workspace_id = await _ensure_direct_workspace(conn, workspace_name)
        user_id = await conn.fetchval(
            "INSERT INTO users (email, display_name, home_org_id) VALUES ($1, $2, $3)"
            " ON CONFLICT ((lower(email))) DO NOTHING RETURNING id",
            email, display_name, org_id,
        )
        if user_id is None:
            # A concurrent first login committed the person first.
            return await conn.fetchval(
                "SELECT id FROM users WHERE lower(email) = lower($1)", email
            )
        await conn.execute(
            "INSERT INTO memberships (workspace_id, user_id, role)"
            " VALUES ($1, $2, 'analyst') ON CONFLICT (workspace_id, user_id) DO NOTHING",
            workspace_id, user_id,
        )
        return user_id

async def resolve_user(request: Request) -> AuthContext:

    settings: Settings = request.app.state.settings
    pool: asyncpg.Pool = request.app.state.pool

    authorization = request.headers.get("Authorization", "")
    if authorization.startswith("Bearer "):
        token = authorization.removeprefix("Bearer ").strip()
        try:
            claims = decode_jwt(settings, token)
            user_id, workspace_id = UUID(claims["sub"]), UUID(claims["wid"])

    if api_key:
        row = await pool.fetchrow(
            """
            SELECT user_id, workspace_id FROM api_keys
            WHERE key_hash = $1 AND revoked_at IS NULL
            """,
            hash_api_key(api_key),
        )

            raise HTTPException(status_code=401, detail="Invalid API key")
        context = await _context(pool, row["user_id"], row["workspace_id"], "api_key")
        await pool.execute(
            "UPDATE api_keys SET last_used_at = now() WHERE key_hash = $1",
            hash_api_key(api_key),
        )
        return context

    raise HTTPException(status_code=401, detail="Not authenticated")

"""The tenancy audit trail (D-061; S30 design §3): who entered or changed a
workspace, and of which organization. Append-only: nothing in auspex/ updates
or deletes a row (pinned by tests/test_tenancy_admin.py)."""

import json
from dataclasses import dataclass
from datetime import datetime
from uuid import UUID

# Must equal the audit_events_action_check list in auspex/migrations.py (pinned).
ACTIONS: frozenset[str] = frozenset({
    "workspace.enter",
    "membership.add",
    "membership.role",
    "membership.remove",
    "membership.provider_wide",
    "org.create",
    "org.restricted",
    "workspace.create",
})
AUDIT_PAGE_MAX = 100


@dataclass(frozen=True)
class Actor:
    kind: str  # "user" | "cli" | "system"
    user_id: UUID | None = None
    org_id: UUID | None = None


CLI = Actor("cli")
SYSTEM = Actor("system")  # dev provisioning


def person(user_id: UUID, org_id: UUID) -> Actor:
    """A signed-in person, stamped with their home organization at write time."""
    return Actor("user", user_id, org_id)


async def record(conn, *, workspace_id: UUID, action: str, actor: Actor,
                 subject_user_id: UUID | None = None, details: dict | None = None) -> None:
    if action not in ACTIONS:
        raise ValueError(f"unknown audit action {action!r}")
    await conn.execute(
        "INSERT INTO audit_events (workspace_id, actor_kind, actor_user_id, actor_org_id,"
        " action, subject_user_id, details) VALUES ($1, $2, $3, $4, $5, $6, $7::jsonb)",
        workspace_id, actor.kind, actor.user_id, actor.org_id, action, subject_user_id,
        json.dumps(details or {}),
    )


async def list_events(db, workspace_id: UUID, *, before: datetime | None = None,
                      limit: int = 50) -> list[dict]:
    """One workspace's events, newest first. `before` pages by created_at."""
    rows = await db.fetch(
        """
        SELECT e.id, e.created_at, e.action, e.actor_kind, e.details,
               e.actor_user_id, au.email AS actor_email, au.display_name AS actor_name,
               e.actor_org_id, ao.name AS actor_org,
               e.subject_user_id, su.email AS subject_email
          FROM audit_events e
          LEFT JOIN users au ON au.id = e.actor_user_id
          LEFT JOIN organizations ao ON ao.id = e.actor_org_id
          LEFT JOIN users su ON su.id = e.subject_user_id
         WHERE e.workspace_id = $1
           AND ($2::timestamptz IS NULL OR e.created_at < $2)
         ORDER BY e.created_at DESC, e.id DESC
         LIMIT $3
        """,
        workspace_id, before, max(1, min(limit, AUDIT_PAGE_MAX)),
    )
    return [
        {
            "id": str(r["id"]),
            "at": r["created_at"].isoformat(),
            "action": r["action"],
            "actor": {
                "kind": r["actor_kind"],
                "user_id": str(r["actor_user_id"]) if r["actor_user_id"] else None,
                "email": r["actor_email"],
                "display_name": r["actor_name"],
                "organization": r["actor_org"],
            },
            "subject": {
                "user_id": str(r["subject_user_id"]) if r["subject_user_id"] else None,
                "email": r["subject_email"],
            },
            "details": json.loads(r["details"]),
        }
        for r in rows
    ]

```python
SELF_CHANGE = "You cannot change your own membership; another admin can."


def _check_name(name: str, what: str) -> str:
    cleaned = name.strip()
    if not cleaned:
        raise Invalid(f"A {what} needs a name")
    if cleaned == DEPLOYMENT_WORKSPACE:
        raise Refused(f"{DEPLOYMENT_WORKSPACE!r} is reserved for the deployment")
    return cleaned


def _check_role(role: str) -> str:
    if role not in ROLES:
        raise Invalid(f"Unknown role {role!r}; the roles are {', '.join(ROLES)}")
    return role


def _check_region(region: str) -> str:
    try:
        return check_region(region)
    except ValueError as err:
        raise Invalid(str(err)) from err


_WORKSPACE_SQL = (
    "SELECT w.id, w.name, w.org_id, o.kind AS org_kind, o.parent_id"
    " FROM workspaces w JOIN organizations o ON o.id = w.org_id"
)


async def _workspace(conn, workspace_id: UUID) -> asyncpg.Record:
    row = await conn.fetchrow(f"{_WORKSPACE_SQL} WHERE w.id = $1", workspace_id)
    if row is None:
        raise NotFound("No such workspace")
    return row


async def _workspace_named(conn, name: str) -> asyncpg.Record:
    row = await conn.fetchrow(f"{_WORKSPACE_SQL} WHERE w.name = $1", name)
    if row is None:
        raise NotFound(f"No workspace named {name!r}")
    return row


async def _organization_named(conn, name: str) -> asyncpg.Record:
    row = await conn.fetchrow("SELECT id, name, kind FROM organizations WHERE name = $1", name)
    if row is None:
        raise NotFound(f"No organization named {name!r}")
    return row


async def _insert_org(conn, name: str, kind: str, parent_id: UUID | None = None,
                      restricted: bool = False) -> UUID:
    try:
        return await conn.fetchval(
            "INSERT INTO organizations (name, kind, parent_id, restricted)"
            " VALUES ($1, $2, $3, $4) RETURNING id",
            name, kind, parent_id, restricted,
        )
    except asyncpg.UniqueViolationError as err:
        raise Conflict(f"An organization named {name!r} already exists") from err


async def _insert_workspace(conn, name: str, org_id: UUID, region: str) -> UUID:
    try:
        return await conn.fetchval(
            "INSERT INTO workspaces (name, org_id, region) VALUES ($1, $2, $3) RETURNING id",
            name, org_id, region,
        )
    except asyncpg.UniqueViolationError as err:
        raise Conflict(f"A workspace named {name!r} already exists") from err


async def _person(conn, email: str, home_org_id: UUID) -> UUID:
    """The person with this email, or a new one homed in `home_org_id`."""
    existing = await conn.fetchval("SELECT id FROM users WHERE lower(email) = lower($1)", email)
    if existing is not None:
        return existing
    created = await conn.fetchval(
        "INSERT INTO users (email, home_org_id) VALUES ($1, $2)"
        " ON CONFLICT ((lower(email))) DO NOTHING RETURNING id",
        email, home_org_id,
    )
    if created is not None:
        return created
    return await conn.fetchval("SELECT id FROM users WHERE lower(email) = lower($1)", email)


async def _add(conn, workspace: asyncpg.Record, user_id: UUID, role: str,
               provider_wide: bool, actor: Actor) -> None:
    """The membership rules, once (D-061 decision 3)."""
    if actor.user_id == user_id:
        raise Refused(SELF_CHANGE)
    home = await conn.fetchval("SELECT home_org_id FROM users WHERE id = $1", user_id)
    if workspace["org_id"] != home and workspace["parent_id"] != home:
        raise Conflict("This person belongs to another organization")
    if provider_wide and workspace["org_kind"] != "provider":
        raise Invalid("Provider-wide applies only on a provider's own workspace")
    added = await conn.fetchval(
        "INSERT INTO memberships (workspace_id, user_id, role, provider_wide)"
        " VALUES ($1, $2, $3, $4) ON CONFLICT (workspace_id, user_id) DO NOTHING RETURNING id",
        workspace["id"], user_id, role, provider_wide,
    )
    if added is None:
        raise Conflict("Already a member; change the role instead")
    await audit.record(conn, workspace_id=workspace["id"], action="membership.add", actor=actor,
                       subject_user_id=user_id,
                       details={"role": role, "provider_wide": provider_wide})


async def _change(conn, workspace: asyncpg.Record, user_id: UUID, actor: Actor,
                  role: str | None, provider_wide: bool | None) -> None:
    if actor.user_id == user_id:
        raise Refused(SELF_CHANGE)
    if role is None and provider_wide is None:
        raise Invalid("Nothing to change")
    current = await conn.fetchrow(
        "SELECT role, provider_wide FROM memberships"
        " WHERE workspace_id = $1 AND user_id = $2 FOR UPDATE",
        workspace["id"], user_id,
    )
    if current is None:
        raise NotFound("Not a member of this workspace")
    if provider_wide and workspace["org_kind"] != "provider":
        raise Invalid("Provider-wide applies only on a provider's own workspace")
    if role is not None and role != current["role"]:
        await conn.execute(
            "UPDATE memberships SET role = $3, updated_at = now()"
            " WHERE workspace_id = $1 AND user_id = $2",
            workspace["id"], user_id, role,
        )
        await audit.record(conn, workspace_id=workspace["id"], action="membership.role",
                           actor=actor, subject_user_id=user_id,
                           details={"from": current["role"], "to": role})
    if provider_wide is not None and provider_wide != current["provider_wide"]:
        await conn.execute(
            "UPDATE memberships SET provider_wide = $3, updated_at = now()"
            " WHERE workspace_id = $1 AND user_id = $2",
            workspace["id"], user_id, provider_wide,
        )
        await audit.record(conn, workspace_id=workspace["id"],
                           action="membership.provider_wide", actor=actor,
                           subject_user_id=user_id, details={"provider_wide": provider_wide})


async def _remove(conn, workspace: asyncpg.Record, user_id: UUID, actor: Actor) -> None:
    if actor.user_id == user_id:
        raise Refused(SELF_CHANGE)
    role = await conn.fetchval(
        "DELETE FROM memberships WHERE workspace_id = $1 AND user_id = $2 RETURNING role",
        workspace["id"], user_id,
    )
    if role is None:
        raise NotFound("Not a member of this workspace")
    await audit.record(conn, workspace_id=workspace["id"], action="membership.remove",
                       actor=actor, subject_user_id=user_id, details={"role": role})


async def _create(conn, *, org_id: UUID, org_name: str, kind: str, workspace: str,
                  region: str, admin_email: str | None, actor: Actor) -> UUID:
    workspace_id = await _insert_workspace(conn, workspace, org_id, region)
    await audit.record(conn, workspace_id=workspace_id, action="org.create", actor=actor,
                       details={"organization": org_name, "kind": kind})
    await audit.record(conn, workspace_id=workspace_id, action="workspace.create", actor=actor,
                       details={"workspace": workspace, "region": region})
    if admin_email is not None:
        user_id = await _person(conn, admin_email, org_id)
        await _add(conn, await _workspace(conn, workspace_id), user_id, "admin", False, actor)
    return workspace_id


async def create_org(pool, *, kind: str, name: str, workspace: str, admin_email: str,
                     region: str = GLOBAL, actor: Actor = CLI) -> tuple[UUID, UUID]:
    """A direct or provider organization, its own workspace and its first admin."""
    if kind not in ("direct", "provider"):
        raise Invalid("create-org makes a direct or a provider organization;"
                      " a client is made with create-client")
    name, workspace = _check_name(name, "organization"), _check_name(workspace, "workspace")
    region, admin_email = _check_region(region), _clean_email(admin_email)
    async with pool.acquire() as conn, conn.transaction():
        org_id = await _insert_org(conn, name, kind)
        workspace_id = await _create(conn, org_id=org_id, org_name=name, kind=kind,
                                     workspace=workspace, region=region,
                                     admin_email=admin_email, actor=actor)
    return org_id, workspace_id


async def create_client(pool, *, provider: str, name: str, workspace: str,
                        region: str = GLOBAL, admin_email: str | None = None,
                        restricted: bool = False, actor: Actor = CLI) -> tuple[UUID, UUID]:
    """A client organization under `provider`, with its workspace."""
    name, workspace = _check_name(name, "organization"), _check_name(workspace, "workspace")
    region = _check_region(region)
    admin_email = _clean_email(admin_email) if admin_email is not None else None
    async with pool.acquire() as conn, conn.transaction():
        parent = await _organization_named(conn, provider)
        if parent["kind"] != "provider":
            raise Invalid(f"{provider!r} is not a provider organization")
        org_id = await _insert_org(conn, name, "client", parent["id"], restricted)
        workspace_id = await _create(conn, org_id=org_id, org_name=name, kind="client",
                                     workspace=workspace, region=region,
                                     admin_email=admin_email, actor=actor)
    return org_id, workspace_id


async def set_restricted(pool, *, client: str, restricted: bool, actor: Actor = CLI) -> None:
    async with pool.acquire() as conn, conn.transaction():
        org = await _organization_named(conn, client)
        if org["kind"] != "client":
            raise Invalid("Only a client organization can be restricted")
        await conn.execute("UPDATE organizations SET restricted = $2 WHERE id = $1",
                           org["id"], restricted)
        for row in await conn.fetch("SELECT id FROM workspaces WHERE org_id = $1", org["id"]):
            await audit.record(conn, workspace_id=row["id"], action="org.restricted",
                               actor=actor, details={"restricted": restricted})


async def add_member(pool, *, workspace_id: UUID, email: str, role: str, actor: Actor) -> UUID:
    email, role = _clean_email(email), _check_role(role)
    async with pool.acquire() as conn, conn.transaction():
        workspace = await _workspace(conn, workspace_id)
        user_id = await _person(conn, email, workspace["org_id"])
        await _add(conn, workspace, user_id, role, False, actor)
        return user_id


async def change_member(pool, *, workspace_id: UUID, user_id: UUID, actor: Actor,
                        role: str | None = None, provider_wide: bool | None = None) -> None:
    if role is not None:
        _check_role(role)
    async with pool.acquire() as conn, conn.transaction():
        await _change(conn, await _workspace(conn, workspace_id), user_id, actor,
                      role, provider_wide)


async def remove_member(pool, *, workspace_id: UUID, user_id: UUID, actor: Actor) -> None:
    async with pool.acquire() as conn, conn.transaction():
        await _remove(conn, await _workspace(conn, workspace_id), user_id, actor)


async def set_member(pool, *, workspace: str, email: str, role: str,
                     provider_wide: bool = False, actor: Actor = CLI) -> UUID:
    """The CLI's upsert: add, or change role and grant, by names."""
    email, role = _clean_email(email), _check_role(role)
    async with pool.acquire() as conn, conn.transaction():
        ws = await _workspace_named(conn, workspace)
        user_id = await _person(conn, email, ws["org_id"])
        member = await conn.fetchval(
            "SELECT 1 FROM memberships WHERE workspace_id = $1 AND user_id = $2",

"""The one way into a workspace (D-061; S30 design §2): a sign-in lands, a
switch names its target, and both are checked against enterable_workspaces and
recorded as `workspace.enter` in the workspace entered."""

from uuid import UUID

from auspex.tenancy import audit
from auspex.tenancy.access import Access, enterable_workspaces, home_org, landing


class NoAccess(Exception):
    """The person may not enter the workspace asked for, or any workspace."""


async def enter(pool, user_id: UUID, *, via: str, workspace_id: UUID | None = None) -> Access:
    if via == "login":
        access = await landing(pool, user_id)
    elif via == "switch" and workspace_id is not None:
        access = (await enterable_workspaces(pool, user_id, only=workspace_id)).get(workspace_id)
    else:
        raise ValueError(f"unknown entry {via!r}")
    if access is None:
        raise NoAccess
    home = await home_org(pool, user_id)
    async with pool.acquire() as conn:
        await audit.record(conn, workspace_id=access.workspace_id, action="workspace.enter",
                           actor=audit.person(user_id, home), details={"via": via})
    return access
```

    """A dependency that admits only `roles` in the ACTIVE workspace (D-061).

## D-068 — S30's tenancy calls: the CLI creates organizations, dev logins auto-provision, one organization per migrated workspace, admins read the audit, global serves global (2026-10-15, S30)

**Context.** D-061 decided the tenancy model and left five questions to S30.
Burhan answered each, one at a time, and approved the design section by
section (docs/superpowers/specs/2026-10-15-s30-tenancy-design.md).

**Decision (Burhan's calls, S30).**
1. **Only a CLI creates organizations and workspaces** (`python -m auspex.tenancy`,
   run in the app container), each with its first admin. Over HTTP, workspace
   admins manage memberships only. There is no operator role, and
   `__deployment__` stays memberless (D-035).
2. **A dev login auto-provisions as before**: an unknown email becomes a person
   homed in `default`'s organization, with an `analyst` membership there.
   **Google sign-in never provisions**; the person must exist (TD-001 still
   gates it).
3. **The migration makes one `direct` organization per existing workspace**;
   users keep their ids. Two user rows sharing a case-folded email stop the
   migration, with a count and no email.
4. **Workspace admins read their own workspace's audit trail**
   (`GET /api/audit`). It records entries (login and switch), membership
   changes, provider-wide grants and the CLI's acts, each with the actor and
   their home organization. Append-only.
5. **Regions are `global` and `ksa`; a processor serves `global` workspaces and
   its own region.** `ENGINE_REGION` unset means `global`, and an unknown value
   stops startup.

**Also decided in the design, ratified with it.**
- An explicit membership's role wins over a provider-wide grant on the same
  workspace.
- A token whose access is gone answers 403; 401 stays for a bad token.
- `POST /api/auth/switch` is the one route that takes a workspace id from
  input, and it needs a login session.
- No one changes their own membership.
- The region refusal sits in the route bodies, not in the test-seam
  factories.
- Dev provisioning is audited with a third actor kind, `system`, beside
  `user` and `cli`.
