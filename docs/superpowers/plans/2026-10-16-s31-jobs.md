# S31 — The Jobs Queue and TD-025's First Half: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A workspace-scoped Postgres jobs queue (fair, leased, retried, token-checked) with an in-app worker whose first job expires proposals nobody decided within 24 h, and an idempotency key on every execution attempt.

**Architecture:** A new package `auspex/jobs/` holds the queue (`queue.py`: enqueue, a `FOR UPDATE SKIP LOCKED` claim that serves workspaces round-robin, token-checked complete/fail) and the worker (`worker.py`: code-declared kinds and schedules, a loop in the ingest scheduler's shape). Proposals gain an `expired` status enforced in settlement's own UPDATE, made visible by the `proposals.expire` job (`auspex/actions/expiry.py`). Settlement hands every handler a derived per-operation idempotency key, and the built-in note action uses it.

**Tech Stack:** Python 3.12, FastAPI 0.139, asyncpg, Postgres (compose, host port 55432), pytest with pytest-asyncio (auto mode), Node's built-in test runner for the page logic.

**Spec:** `docs/superpowers/specs/2026-10-16-s31-jobs-design.md` (read it first). The reality it stands on is `docs/probes/2026-10-16-s31-jobs-baseline.md`, and the contract is D-065 and D-066 in `DECISIONS.md`.

## Review Focus

These failure modes are implied by the spec but no headline test exercises them. Each line has its pinning test added to the task that owns the code.

1. **A handler that outlives its lease.** The job is re-claimed while the first run is still going. The first run's `complete` must be refused (`JobLost`), logged and not raised, and the tick must go on. Pinned in Task 4.
2. **A handler that returns something JSON cannot carry** (a `datetime` in its result dict). `complete` raises `TypeError` from `json.dumps`. The worker must `fail` the job (it retries) and not crash the tick. Pinned in Task 4.
3. **An enormous error message** (a handler raising with 100 000 characters) must be stored capped at `MAX_ERROR_CHARS`, never whole. Pinned in Task 2.
4. **Two app replicas, one bucket.** A second worker instance in the same schedule bucket must enqueue nothing new. Pinned in Task 4.
5. **The TTL boundary.** Approve and the sweep use complementary conditions (`created_at > now() − TTL` against `created_at <= now() − TTL`), so a row is never both decidable and expirable. Pinned in Task 5 with a row 5 s inside and 1 s outside.

```python
"""The jobs queue (D-065; docs/superpowers/specs/2026-10-16-s31-jobs-design.md).

Our own Postgres table, claimed with `FOR UPDATE SKIP LOCKED`, in settlement's
style: every transition is one conditional UPDATE, and a claim is a token. A job
belongs to one workspace (D-008). What a job does is code: a `JobKind` declares
its handler, lease and attempts beside the handler.

A handler must be idempotent on the job's `idempotency_key`. A lease that
expires means the job can run again (that is what a lease is for), and the key
is how the second run knows it is the second.

Every query here is literal text, never assembled from Python strings.
"""

from __future__ import annotations

import json
from collections.abc import Awaitable, Callable
from dataclasses import dataclass
from datetime import datetime
from uuid import UUID

import asyncpg

JobHandler = Callable[[asyncpg.Pool, "Job"], Awaitable[dict]]


@dataclass(frozen=True)
class JobKind:
    """One kind of job, declared in code beside its handler."""

    name: str
    handler: JobHandler
    lease_seconds: int = 60
    max_attempts: int = 5

    def __post_init__(self) -> None:
        if not self.name.strip():
            raise ValueError("a job kind needs a name")
        if self.lease_seconds < 1 or self.max_attempts < 1:
            raise ValueError(f"{self.name}: lease_seconds and max_attempts must be at least 1")


def _json(value):
    return json.loads(value) if isinstance(value, str) else value


@dataclass(frozen=True)
class Job:
    id: UUID
    workspace_id: UUID
    kind: str
    integration_id: UUID | None
    payload: dict
    idempotency_key: str
    status: str
    attempts: int
    max_attempts: int
    lease_seconds: int
    claim_token: UUID | None
    claimed_by: str | None
    result: dict | None
    last_error: str | None

    @classmethod
    def from_row(cls, row: asyncpg.Record) -> Job:
        return cls(
            id=row["id"],
            workspace_id=row["workspace_id"],
            kind=row["kind"],
            integration_id=row["integration_id"],
            payload=_json(row["payload"]) or {},
            idempotency_key=row["idempotency_key"],
            status=row["status"],
            attempts=row["attempts"],
            max_attempts=row["max_attempts"],
            lease_seconds=row["lease_seconds"],
            claim_token=row["claim_token"],
            claimed_by=row["claimed_by"],
            result=_json(row["result"]),
            last_error=row["last_error"],
        )


async def enqueue(
    pool: asyncpg.Pool,
    *,
    workspace_id: UUID,
    kind: JobKind,
    idempotency_key: str,
    payload: dict | None = None,
    integration_id: UUID | None = None,
    run_after: datetime | None = None,
) -> tuple[Job, bool]:
    """A job, once per (workspace, key). When the key is already taken, by a job
    in any status, `done` and `dead` included, nothing is written and the
    existing job comes back with `created=False`."""
    if not idempotency_key.strip():
        raise ValueError("a job needs an idempotency key")
    row = await pool.fetchrow(
        """
        INSERT INTO jobs (workspace_id, kind, integration_id, payload, idempotency_key,
                          max_attempts, lease_seconds, run_after)
        VALUES ($1, $2, $3, $4::jsonb, $5, $6, $7, COALESCE($8, now()))
        ON CONFLICT (workspace_id, idempotency_key) DO NOTHING
        RETURNING *
        """,
        workspace_id, kind.name, integration_id, json.dumps(payload or {}),
        idempotency_key, kind.max_attempts, kind.lease_seconds, run_after,
    )
    if row is not None:
        return Job.from_row(row), True
    existing = await pool.fetchrow(
        "SELECT * FROM jobs WHERE workspace_id = $1 AND idempotency_key = $2",
        workspace_id, idempotency_key,
    )
    return Job.from_row(existing), False
```

```python
# Backoff after a failure (Burhan's call, S31): 30 s, doubling, capped at 15 min.
BACKOFF_BASE_SECONDS = 30
BACKOFF_CAP_SECONDS = 900
# A handler's error is stored for a human, not kept whole: a 1 MB message is a
# row nobody can read and a column nobody should have to page through.
MAX_ERROR_CHARS = 2000


class JobLost(RuntimeError):
    """The claimer no longer holds the job: its lease was re-claimed, the job
    went dead, or it was already finished. Its answer is refused."""


@dataclass(frozen=True)
class ClaimScope:
    """What one claimer may take (§1). `kinds` is what it can run. A
    `workspace_ids` of None is every workspace (the in-app worker); S33's Edge
    Agent passes its one. An `integration_ids` of None means jobs bound to NO
    integration; a set means only those integrations' jobs, so nobody claims an
    integration's job without naming the integration."""

    kinds: frozenset[str]
    workspace_ids: frozenset[UUID] | None = None
    integration_ids: frozenset[UUID] | None = None

    def __post_init__(self) -> None:
        if not self.kinds:
            raise ValueError("a claim names the kinds it can run")


def _ids(values: frozenset[UUID] | None) -> list[UUID] | None:
    return None if values is None else list(values)


async def claim(pool: asyncpg.Pool, scope: ClaimScope, *, claimer: str) -> Job | None:
    """The next ready job in `scope`, claimed: a fresh token, one more attempt,
    a lease. Ready means queued and due, or claimed with a lease that expired
    and attempts left. One transaction: first the expired leases with no
    attempts left go `dead`, then one statement picks and claims, skipping rows
    another claimer holds locked."""
    kinds, workspaces, integrations = (
        list(scope.kinds), _ids(scope.workspace_ids), _ids(scope.integration_ids))
    async with pool.acquire() as conn, conn.transaction():
        await conn.execute(
            """
            UPDATE jobs
               SET status = 'dead', last_error = 'lease expired', claim_token = NULL,
                   lease_expires_at = NULL, finished_at = now()
             WHERE status = 'claimed' AND lease_expires_at < now()
               AND attempts >= max_attempts
               AND kind = ANY($1::text[])
               AND ($2::uuid[] IS NULL OR workspace_id = ANY($2::uuid[]))
               AND CASE WHEN $3::uuid[] IS NULL THEN integration_id IS NULL
                        ELSE integration_id = ANY($3::uuid[]) END
            """,
            kinds, workspaces, integrations,
        )
        row = await conn.fetchrow(
            """
            WITH pick AS (
                SELECT j.id FROM jobs j
                 WHERE j.kind = ANY($1::text[])
                   AND ($2::uuid[] IS NULL OR j.workspace_id = ANY($2::uuid[]))
                   AND CASE WHEN $3::uuid[] IS NULL THEN j.integration_id IS NULL
                            ELSE j.integration_id = ANY($3::uuid[]) END
                   AND ((j.status = 'queued' AND j.run_after <= now())
                        OR (j.status = 'claimed' AND j.lease_expires_at < now()
                            AND j.attempts < j.max_attempts))
                 ORDER BY j.run_after, j.id
                 LIMIT 1
                 FOR UPDATE OF j SKIP LOCKED
            )
            UPDATE jobs
               SET status = 'claimed', claim_token = gen_random_uuid(), claimed_by = $4,
                   attempts = jobs.attempts + 1,
                   lease_expires_at = now() + make_interval(secs => jobs.lease_seconds)
              FROM pick
             WHERE jobs.id = pick.id
            RETURNING jobs.*
            """,
            kinds, workspaces, integrations, claimer,
        )
    return Job.from_row(row) if row is not None else None


async def complete(pool: asyncpg.Pool, job_id: UUID, token: UUID, result: dict) -> None:
    """Record a job's answer, only for the claim that still holds it."""
    done = await pool.fetchval(
        """
        UPDATE jobs
           SET status = 'done', result = $3::jsonb, claim_token = NULL,
               lease_expires_at = NULL, finished_at = now()
         WHERE id = $1 AND status = 'claimed' AND claim_token = $2
        RETURNING id
        """,
        job_id, token, json.dumps(result),
    )
    if done is None:
        raise JobLost(f"job {job_id} is no longer held by this claim")


async def fail(pool: asyncpg.Pool, job_id: UUID, token: UUID, error: str, *,
               permanent: bool = False) -> str:
    """A failed attempt, only for the claim that still holds it. With attempts
    left the job is queued again after the backoff; with none it is `dead`; a
    permanent failure is `failed` and never retried. Returns the new status."""
    status = await pool.fetchval(
        """
        UPDATE jobs
           SET status = CASE WHEN $4 THEN 'failed'
                             WHEN attempts >= max_attempts THEN 'dead'
                             ELSE 'queued' END,
               run_after = CASE WHEN $4 OR attempts >= max_attempts THEN run_after
                                ELSE now() + make_interval(secs => LEAST(
                                    $5::double precision * power(2, attempts - 1),
                                    $6::double precision)) END,
               finished_at = CASE WHEN $4 OR attempts >= max_attempts THEN now() END,
               last_error = $3, claim_token = NULL, lease_expires_at = NULL
         WHERE id = $1 AND status = 'claimed' AND claim_token = $2
        RETURNING status
        """,
        job_id, token, error[:MAX_ERROR_CHARS], permanent,
        float(BACKOFF_BASE_SECONDS), float(BACKOFF_CAP_SECONDS),
    )
    if status is None:
        raise JobLost(f"job {job_id} is no longer held by this claim")
    return status
```

```python
logger = logging.getLogger(__name__)

POLL_SECONDS = 5
# Bounded so one tick returns to its schedules and its sleep even under a
# backlog; the next tick carries on where this one stopped.
MAX_JOBS_PER_TICK = 50


@dataclass(frozen=True)
class Schedule:
    """A kind enqueued for each workspace `due_workspaces` names, once per
    `every_seconds` bucket of the wall clock. The bucket is in the job's
    idempotency key, so two ticks, or two app replicas, enqueue it once."""

    kind: JobKind
    every_seconds: int
    due_workspaces: Callable[[asyncpg.Pool], Awaitable[list[UUID]]]


@dataclass(frozen=True)
class TickReport:
    enqueued: int
    ran: int
    failed: int


def _error_text(exc: BaseException) -> str:
    return f"{type(exc).__name__}: {exc}"[:MAX_ERROR_CHARS]


class JobWorker:
    def __init__(
        self,
        pool: asyncpg.Pool,
        kinds: Sequence[JobKind],
        schedules: Sequence[Schedule] = (),
        *,
        name: str = "app-worker",
        enabled: bool = True,
        poll_seconds: float = POLL_SECONDS,
        max_per_tick: int = MAX_JOBS_PER_TICK,
        now: Callable[[], datetime] = lambda: datetime.now(UTC),
        sleep: Callable[[float], Awaitable[None]] = asyncio.sleep,
    ) -> None:
        self._kinds = {k.name: k for k in kinds}
        if len(self._kinds) != len(kinds):
            raise ValueError("two job kinds share a name")
        for schedule in schedules:
            if schedule.kind.name not in self._kinds:
                raise ValueError(f"a schedule for {schedule.kind.name!r}, a kind this worker"
                                 " does not run")
        self._scope = ClaimScope(kinds=frozenset(self._kinds))
        self._pool = pool
        self._schedules = tuple(schedules)
        self._name = name
        self.enabled = enabled
        self._poll = poll_seconds
        self._max = max_per_tick
        self._now = now
        self._sleep = sleep
        self._last_bucket: dict[str, int] = {}

    async def run(self) -> None:
        if not self.enabled:
            logger.info("jobs worker disabled (JOBS_WORKER_ENABLED=false)")
            return
        while True:
            try:
                report = await self.tick()
                if report.enqueued or report.ran or report.failed:
                    logger.info("jobs tick: %s", report)
            except asyncio.CancelledError:
                raise
            except Exception:  # noqa: BLE001 — the loop must survive anything
                logger.exception("jobs tick failed; retrying next interval")
            await self._sleep(self._poll)

    async def tick(self) -> TickReport:
        enqueued = await self._run_schedules()
        ran = failed = 0
        for _ in range(self._max):
            job = await claim(self._pool, self._scope, claimer=self._name)
            if job is None:
                break
            try:
                result = await self._kinds[job.kind].handler(self._pool, job)
                await complete(self._pool, job.id, job.claim_token, result or {})
            except asyncio.CancelledError:
                raise
            except JobLost:
                # Its lease was re-claimed while it ran (or it went dead): the
                # answer belongs to whoever holds it now. Logged, never raised.
                logger.warning("job %s (%s) finished after losing its claim", job.id, job.kind)
                continue
            except Exception as exc:  # noqa: BLE001 — a failing job must not stop the tick
                failed += 1
                try:
                    await fail(self._pool, job.id, job.claim_token, _error_text(exc))
                except JobLost:
                    logger.warning("job %s (%s) failed after losing its claim", job.id, job.kind)
                logger.warning("job %s (%s) failed: %s", job.id, job.kind, _error_text(exc))
                continue
            ran += 1
        return TickReport(enqueued=enqueued, ran=ran, failed=failed)

    async def _run_schedules(self) -> int:
        enqueued = 0
        stamp = int(self._now().timestamp())
        for schedule in self._schedules:
            bucket = stamp // schedule.every_seconds
            if self._last_bucket.get(schedule.kind.name) == bucket:
                continue
            try:
                workspaces = await schedule.due_workspaces(self._pool)
                for workspace_id in workspaces:
                    _, created = await enqueue(
                        self._pool, workspace_id=workspace_id, kind=schedule.kind,
                        idempotency_key=f"{schedule.kind.name}:{bucket}",
                    )
                    enqueued += int(created)
            except asyncio.CancelledError:
                raise
            except Exception:  # noqa: BLE001 — a broken schedule must not stop the jobs
                logger.exception("schedule %s failed; it retries next tick", schedule.kind.name)
                continue
            self._last_bucket[schedule.kind.name] = bucket
        return enqueued
```

```python
"""The first job kind (S31 design §2): proposals nobody decided within the TTL
become `expired`.

Not the guarantee: approve and reject already refuse an overdue proposal in the
```
