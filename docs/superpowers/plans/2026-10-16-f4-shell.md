# One Shell for Every Page (F4) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Chat, the timeline and a new read-only Members page share one sign-in per tab, one header (role-aware navigation, a workspace switcher that reloads the page) and one set of tested modules, with 304s for every page file.

**Architecture:** Each page's markup holds an empty `<header id="shell">` (plus its own controls in `.page-lead` / `.page-tools`), filled by `js/shell.js`, which owns the token, `GET /api/auth/me`, the switch and sign-out. Pure logic lives in `js/shell-logic.js`; every request goes through `js/api.js`; every element through `js/dom.js`'s `el`. A switch stores the new token and reloads without the hash (D-070); any 403 re-checks `/me`.

**Tech Stack:** FastAPI `FileResponse`/`Response`, plain ES modules (no build), Node's built-in test runner run from pytest, pytest + FastAPI `TestClient`.

**Spec:** `docs/superpowers/specs/2026-10-16-f4-shell-design.md` (read it with this plan). Reality: `docs/probes/2026-10-16-f4-s30-routes.md`.

## Global Constraints

- **D-057 on every page:** no `<style>`, no inline `<script>`, no `on…=` attribute, no `style=` attribute in any page's markup; files served only from `auspex/routes/ui.py`'s allow-list; every page served with `_CHAT_CSP`. No new external origin.
- **Text, never HTML:** server, model and feed strings reach the page through `el()` children or `textContent`. No `innerHTML`, `outerHTML`, `insertAdjacentHTML` or `document.write` in any new or edited module (chat.js keeps only its three existing fixed templates in `addMsg`/`ensureThink`).
- **Route files never read `request.headers`, `query_params` or `path_params`** (`tests/test_tenancy_roles.py::test_no_handler_reads_raw_input_around_the_walk`). Read a header as a declared FastAPI `Header()` parameter.
- **Storage:** only `js/shell.js` touches `sessionStorage`, through three guarded helpers; the token key stays `"auspex.token"`. Never `localStorage`.
- **Copy, verbatim (spec):**
  - `CONNECTION_LOST` = `The connection dropped before this turn finished. Reopen the chat to see what was kept.`
  - `INVALID` = `The request was not valid.`
  - `EXPIRED` = `Your sign-in expired. Sign in again.`
  - `NETWORK` = `Couldn't reach the server.`
  - viewer note = `You are a viewer in <workspace>: you can read here; asking the co-analyst and deciding proposals need the analyst or admin role.`
  - approvals panel, viewer = `Deciding needs the analyst or admin role.`
  - signed out: `Sign in to see the digest.` (timeline), `Sign in to see this workspace's members.` (members).
- **Brand (D-002):** no engine/provider name in any page file (`FORBIDDEN_ENGINE_NAMES`); the co-analyst is never a "copilot".
- **Commits:** one concern per commit, `feat|fix|chore|docs|test(scope): summary`, never amend, end every message with:
  ```
  Co-Authored-By: Claude Opus 5.5 (1M context) <noreply@anthropic.com>
  Claude-Session: https://claude.ai/code/session_01JbR7Kn3Xh1CS8xL6cThrpx
  ```
- **README test count:** every commit that adds or removes tests updates it:
  ```bash
  NEW=$(.venv/bin/pytest --collect-only -q 2>/dev/null | tail -1 | grep -o '^[0-9]*')
  OLD=$(grep -o '[0-9][0-9,]* tests' README.md | head -1 | grep -o '^[0-9,]*')
  sed -i "s/${OLD} tests/${NEW} tests/g" README.md
  ```
- **Running tests:** `.venv/bin/pytest <files> -q` (conftest pins the host env; Postgres and OpenSearch must be up: `docker compose up -d --wait postgres opensearch`). Node: `node --test --test-reporter=spec tests/js/<file>.test.mjs`. Lint with the gate's scope: `.venv/bin/ruff check auspex tests scripts server.py`.
- **Do not run `./ci.sh` from an implementer task** (it rebuilds the live container); the controller runs the full gate.

## Review Focus

1. **Storage that will not keep the new token during a switch** (a privacy mode that blocks `sessionStorage`): the page must not reload into a signed-out tab; it stays where it was and says so. → Task 4 (`STORAGE_BLOCKED` before the reload, pinned).
2. **A workspace or organization name that is markup, carries a right-to-left override, or is very long** (the CLI accepts any name): it must render as inert text, and at 390 px must not push Sign out off screen. → Task 2 (the label returns the name unmodified), Task 4 (no `innerHTML` in the shell; ellipsis CSS), Task 11 (live, with such a name at 390 px).
3. **`/me` whose list lacks the active workspace** (a membership vanishing between the token check and the list): the header must still name where the tab is. → Task 2 (`activeWorkspace` fallback test).
4. **Two switches fired before the first reload lands** (a fast double change of the select): exactly one switch request. → Task 4 (the select disabled before the request, pinned).
5. **A role changed while the page is open** (an admin demoted to analyst): the next refusal's re-check must reload the page so doors re-derive from the new role, not leave admin doors standing. → Task 2 (`roleChanged` test), Task 4 (pinned in `recheck`).

```python
"""Minimal dark-first UI shell (S3 step 5).

Serves the pages (their markup, plus the CSS and ES modules each loads, from an
allow-list, TD-045) — chat and the timeline. Dark-first, Auspex palette
(CLAUDE.md brand). The underlying engine/model is never named in any
user-visible string — the UI only ever says "Auspex" / "Co-analyst".
"""

import os
from pathlib import Path
from typing import Annotated

from fastapi import APIRouter, Header, HTTPException
from fastapi.responses import FileResponse, Response

router = APIRouter(tags=["ui"])

_STATIC = Path(__file__).resolve().parent.parent / "static"
_INDEX = _STATIC / "index.html"
_TIMELINE = _STATIC / "timeline.html"
# B-003: with only `last-modified`, a browser caches the page on heuristic
# freshness and keeps running the old one after a deploy. `no-cache` makes every
# load ask first; TD-047: a matching ETag is answered 304, not the file again.
_REVALIDATE = {"Cache-Control": "no-cache"}
# D-057: each page runs only its own scripts and talks only to its own origin;
# TD-045 (chat) and TD-051 (timeline) moved every script and style rule out of
# the pages to make that possible without 'unsafe-inline'.
_CHAT_CSP = "; ".join([
    "default-src 'self'",
    "script-src 'self'",
    "style-src 'self' https://fonts.googleapis.com",
    "font-src https://fonts.gstatic.com",
    "connect-src 'self'",
    "img-src 'self' data:",
    "object-src 'none'",
    "base-uri 'none'",
    "form-action 'none'",
    "frame-ancestors 'none'",
])
_PAGE_HEADERS = {**_REVALIDATE, "Content-Security-Policy": _CHAT_CSP}
# TD-045, TD-051: each page's own files, by name. An allow-list, so no name a
# request can make reaches anything else on disk.
_ASSETS = {
    "css/chat.css": ("text/css", _STATIC / "css" / "chat.css"),
    "js/page-logic.js": ("text/javascript", _STATIC / "js" / "page-logic.js"),
    "js/chat.js": ("text/javascript", _STATIC / "js" / "chat.js"),
    "css/timeline.css": ("text/css", _STATIC / "css" / "timeline.css"),
    "js/timeline-logic.js": ("text/javascript", _STATIC / "js" / "timeline-logic.js"),
    "js/timeline.js": ("text/javascript", _STATIC / "js" / "timeline.js"),
}

# A declared header, not `request.headers`: the tenancy walk forbids reading raw
# input in a route file (tests/test_tenancy_roles.py).
IfNoneMatch = Annotated[str | None, Header()]


def _matches(if_none_match: str | None, etag: str) -> bool:
    """RFC 9110's weak comparison for If-None-Match: any listed tag, `W/` or
    not, or `*`."""
    if not if_none_match:
        return False
    tags = {t.strip().removeprefix("W/") for t in if_none_match.split(",")}
    return "*" in tags or etag in tags


def _serve(path: Path, media_type: str, headers: dict[str, str],
           if_none_match: str | None) -> Response:
    """The file, or a 304 when the browser already holds this version (TD-047).
    The stat is read first so the ETag is known before answering; the 304
    carries the same headers a 200 would, so a page's policy is never missing."""
    resp = FileResponse(path, media_type=media_type, headers=headers, stat_result=os.stat(path))
    etag = resp.headers["etag"]
    if _matches(if_none_match, etag):
        return Response(status_code=304, headers={**headers, "ETag": etag})
    return resp


def _asset(key: str, if_none_match: str | None) -> Response:
    entry = _ASSETS.get(key)
    if entry is None:
        raise HTTPException(status_code=404, detail="Not Found")
    media_type, path = entry
    return _serve(path, media_type, _REVALIDATE, if_none_match)


@router.get("/", include_in_schema=False)
async def index(if_none_match: IfNoneMatch = None) -> Response:
    return _serve(_INDEX, "text/html", _PAGE_HEADERS, if_none_match)


@router.get("/timeline", include_in_schema=False)
async def timeline(if_none_match: IfNoneMatch = None) -> Response:
    """S16 — a verdict's life in one place, and the "your past got re-scored"
    digest. Reads /api/timeline only; the page holds no decay arithmetic of its
    own, so a band means the same thing on screen as it does in the payload."""
    return _serve(_TIMELINE, "text/html", _PAGE_HEADERS, if_none_match)


@router.get("/css/{name}", include_in_schema=False)
async def stylesheet(name: str, if_none_match: IfNoneMatch = None) -> Response:
    return _asset(f"css/{name}", if_none_match)


@router.get("/js/{name}", include_in_schema=False)
async def script(name: str, if_none_match: IfNoneMatch = None) -> Response:
    return _asset(f"js/{name}", if_none_match)
```

```js
// The shell's pure logic (F4, docs/superpowers/specs/2026-10-16-f4-shell-design.md):
// no DOM, no fetch. js/shell.js and the pages import it, and
// tests/js/shell_logic.test.mjs imports it under Node, so what is tested is
// what the browser runs. The server decides who may enter what, and as which
// role (D-061); this module only words and orders what GET /api/auth/me
// returned. It never filters it and never adds to it (D-070).

export const PAGES = [
  { page: "chat", href: "/", label: "Chat" },
  { page: "timeline", href: "/timeline", label: "Timeline" },
  { page: "members", href: "/members", label: "Members", admin: true },
];

export function isAdmin(role) { return role === "admin"; }
export function mayChange(role) { return role === "analyst" || role === "admin"; }

// The header's page links. Signed out (`me` null), only the pages anyone may
// open; an admin entry only for an admin of the ACTIVE workspace.
export function navEntries(me, page) {
  const role = me && me.workspace ? me.workspace.role : null;
  return PAGES.filter((p) => !p.admin || isAdmin(role))
    .map((p) => ({ href: p.href, label: p.label, current: p.page === page }));
}

// One workspace as the header names it. The organization leads: which client
// you are in is the thing that must never be in doubt. Names are returned as
// written; the DOM makes them text.
export function workspaceLabel(ws) {
  const org = ws.organization || {};
  const name = org.name && org.name !== ws.name ? `${org.name} / ${ws.name}` : ws.name;
  const parts = [name, org.kind, ws.role];
  if (ws.region && ws.region !== "global") parts.push(ws.region);
  return parts.filter(Boolean).join(" · ");
}

// The active workspace's own entry (its organization carries a kind there).
// Missing from the list (a membership vanishing mid-request), it is rebuilt
// from `me.workspace`, which names its organization only.
export function activeWorkspace(me) {
  const found = (me.workspaces || []).find((w) => w.id === me.workspace.id);
  return found || { ...me.workspace, organization: { name: me.workspace.organization } };
}

export function switchOptions(me) {
```

```js
// The one API client (F4). Every request a page makes goes through it, so the
// bearer header is written here and nowhere else. It does not judge a
// refusal: a 403 is handed to the shell, which asks GET /api/auth/me whether
// this tab may still be here (D-070); a 401 ends the sign-in. `fetch` is
// injected, so tests/js/api.test.mjs drives it under Node.
import { errorText } from "./shell-logic.js";

export function createApi({ fetch, token, onForbidden = () => {}, onExpired = () => {} }) {
  const headers = (json) => {
    const h = json ? { "Content-Type": "application/json" } : {};
    const t = token();
    if (t) h.Authorization = "Bearer " + t;
    return h;
  };
  const refused = (status) => {
    if (status === 401) onExpired();
    else if (status === 403) onForbidden();
  };
  const readBody = async (r) => { try { return await r.json(); } catch (e) { return null; } };

  async function request(method, path, body) {
    let r;
    try {
      r = await fetch(path, {
        method, headers: headers(body !== undefined),
        body: body === undefined ? undefined : JSON.stringify(body),
      });
    } catch (e) {
      return { ok: false, status: 0, body: null, detail: errorText(0, null) };
    }
    const parsed = await readBody(r);
    if (!r.ok) refused(r.status);
    return { ok: r.ok, status: r.status, body: parsed, detail: r.ok ? null : errorText(r.status, parsed) };
  }

  return {
    get: (path) => request("GET", path),
    post: (path, body) => request("POST", path, body),
    // Server-sent events: the Response itself, unread, once it streams. A
    // refusal before the stream (the input rail's 400, residency's 403, the
    // usage ceiling's 429) answers like get and post.
    async stream(path, body) {
      let r;
      try {
        r = await fetch(path, { method: "POST", headers: headers(true), body: JSON.stringify(body) });
      } catch (e) {
        return { ok: false, status: 0, body: null, detail: errorText(0, null) };
      }
      if (r.ok) return { ok: true, status: r.status, response: r };
      const parsed = await readBody(r);
      refused(r.status);
      return { ok: false, status: r.status, body: parsed, detail: errorText(r.status, parsed) };
    },
  };
}
```

```js
// The shell every page shares (F4, docs/superpowers/specs/2026-10-16-f4-shell-design.md):
// the header, the tab's one sign-in (D-056), the workspace switcher, and
// D-070's rules. A switch reloads the page without its hash, so nothing of
// the previous client survives it; GET /api/auth/me is the page's only judge
// of access. Every server string is text (dom.js's el).
import { $, el } from "./dom.js";
import { createApi } from "./api.js";
import {
  navEntries, switchOptions, activeWorkspace, workspaceLabel, roleChanged, afterSwitchUrl,
  EXPIRED, STORAGE_BLOCKED,
} from "./shell-logic.js";

// D-056: the sign-in survives a reload in this tab, and dies with the tab. The
// notice carries one sentence across the reload that ends a sign-in. Storage
// that is blocked or missing leaves the page working for this load only.
const TOKEN_KEY = "auspex.token";
const NOTICE_KEY = "auspex.notice";
function stored(key) { try { return sessionStorage.getItem(key); } catch (e) { return null; } }
function store(key, value) { try { sessionStorage.setItem(key, value); } catch (e) { /* kept in memory only */ } }
function forget(key) { try { sessionStorage.removeItem(key); } catch (e) { /* nothing was kept */ } }

const browserFetch = (...args) => window.fetch(...args);

// `page` names the page for the navigation. `ready({ me, api, setBusy })` runs
// once /me accepts this tab's token; `signedOut()` when the tab holds none.
export function startShell({ page, ready, signedOut }) {
  let token = stored(TOKEN_KEY);
  let me = null;
  let busy = false;
  let checking = null;
  let picker = null;  // the workspace <select>, when there is more than one
  let out = null;     // Sign out

  const header = $("shell");
  const nav = el("nav", { className: "pages" });
  nav.setAttribute("aria-label", "Pages");
  const workspace = el("div", { className: "workspace" });
  const session = el("div", { className: "session" });
  const status = el("span", { id: "status" });
  header.replaceChildren(...[
    header.querySelector(".page-lead"),
    el("span", { className: "mark" }, ["Auspex", el("span", { className: "dot" }, ["."])]),
    el("span", { className: "tag" }, ["the flock sees first"]),
    nav,
    header.querySelector(".page-tools"),
    el("span", { className: "spacer" }),
    workspace, session, status,
  ].filter(Boolean));

  const setStatus = (text, cls) => { status.textContent = text || ""; status.className = cls || ""; };

  // `bare` makes the requests that ARE the check, or come before a sign-in
  // (/me, the switch, the dev login): they must not trigger the re-check.
  const bare = createApi({ fetch: browserFetch, token: () => token });
  const api = createApi({
    fetch: browserFetch, token: () => token, onForbidden: recheck, onExpired: () => end(EXPIRED),
  });

  // D-070: this tab's sign-in is over. One sentence (the server's, or EXPIRED)
  // waits for the signed-out page the reload brings.
  function end(sentence) {
    forget(TOKEN_KEY);
    token = null;
    if (sentence) store(NOTICE_KEY, sentence);
    location.replace(afterSwitchUrl(location));
  }

  // Any 403 asks /me whether this tab may still be here. One check at a time:
  // a poll and a door refused together ask once.
  function recheck() {
    if (!checking) {
      checking = (async () => {
        const r = await bare.get("/api/auth/me");
        if (r.status === 401) end(EXPIRED);
        else if (r.status === 403) end(r.detail);
        else if (r.ok && me && roleChanged(me, r.body)) location.reload();
        else if (r.ok) { me = r.body; showSignedIn(); }  // a role refusal: the caller shows the server's words
      })().finally(() => { checking = null; });
    }
    return checking;
  }

  async function enter() {
    setStatus("signing in…");
    const r = await bare.get("/api/auth/me");
    if (r.ok) {
      me = r.body;
      showSignedIn();
      setStatus("signed in", "ok");
      ready({ me, api, setBusy });
      return;
    }
    if (r.status === 401 || r.status === 403) {
      forget(TOKEN_KEY);
      token = null;
      showSignedOut(r.status === 401 ? EXPIRED : r.detail);
      return;
    }
    setStatus(r.detail, "err");  // the network or the server failed: the token is kept
  }

  async function signIn(email) {
    if (!email) { setStatus("enter an email", "err"); return; }
    setStatus("signing in…");
    const r = await bare.post("/api/auth/dev-login", { email });
    if (!r.ok) { setStatus(r.detail, "err"); return; }
    token = r.body.access_token;
    store(TOKEN_KEY, token);
    await enter();
  }

  async function switchTo() {
    const target = picker.value;
    if (busy || target === me.workspace.id) { picker.value = me.workspace.id; return; }
    picker.disabled = true;  // one switch at a time
    setStatus("switching…");
    const r = await bare.post("/api/auth/switch", { workspace_id: target });
    if (r.ok) {
      store(TOKEN_KEY, r.body.access_token);
      if (stored(TOKEN_KEY) === r.body.access_token) {
        location.replace(afterSwitchUrl(location));
        return;
      }
      setStatus(STORAGE_BLOCKED, "err");  // a reload would land signed out
    } else if (r.status === 401) {
      end(EXPIRED);
      return;
    } else {
      setStatus(r.detail, "err");
    }
    picker.value = me.workspace.id;
    picker.disabled = busy;
    recheck();  // the set may have changed since it was read
  }

  function signOut() {
    if (busy) return;
    forget(TOKEN_KEY);
    location.replace(afterSwitchUrl(location));
  }

  function showNav() {
    nav.replaceChildren(...navEntries(me, page).map((n) => {
      const a = el("a", { href: n.href, className: n.current ? "current" : "" }, [n.label]);
      if (n.current) a.setAttribute("aria-current", "page");
      return a;
    }));
  }

  function showSignedIn() {
    showNav();
    const options = switchOptions(me);
    const label = workspaceLabel(activeWorkspace(me));
    if (options.length > 1) {
      picker = el("select", { id: "workspace", disabled: busy, title: label },
        options.map((o) => el("option", { value: o.id, selected: o.selected }, [o.text])));
      picker.setAttribute("aria-label", "Workspace");
      picker.addEventListener("change", switchTo);
      workspace.replaceChildren(picker);
    } else {
      picker = null;
      workspace.replaceChildren(el("span", { id: "workspace", className: "ws-label", title: label }, [label]));
    }
    out = el("button", { id: "signout", className: "ghost", disabled: busy }, ["Sign out"]);
    out.addEventListener("click", signOut);
    session.replaceChildren(out);
  }

  function showSignedOut(notice) {
    me = null;
    picker = null;
    out = null;
    showNav();
    workspace.replaceChildren();
    const email = el("input", { id: "email", type: "email", placeholder: "you@analyst.dev", autocomplete: "off" });
    const go = el("button", { id: "signin", className: "ghost" }, ["Sign in"]);
    go.addEventListener("click", () => signIn(email.value.trim()));
    email.addEventListener("keydown", (e) => { if (e.key === "Enter") signIn(email.value.trim()); });
    session.replaceChildren(email, go);
    setStatus(notice || "not signed in", notice ? "err" : "");
    signedOut();
  }

  // A page in the middle of something (chat's streaming turn) holds the
  // switcher and Sign out still: a reload would cut it.
  function setBusy(on) {
    busy = on;
    if (picker) picker.disabled = on;
    if (out) out.disabled = on;
  }

  const notice = stored(NOTICE_KEY);
  if (notice) forget(NOTICE_KEY);
  if (token) enter();
  else showSignedOut(notice);
  return { api, setBusy };
}
```

- [ ] **Step 1: Append D-070 to `DECISIONS.md`**

```markdown
## D-070 — The page's tenancy rules: a switch reloads, /me judges access (2026-10-16, F4)

**Context.** S30 made a token one workspace and gave people several (D-061,
D-068); F4 gave every page one shell with a workspace switcher
(docs/superpowers/specs/2026-10-16-f4-shell-design.md). A page that swapped
the token in place would have to find and stop every timer, poll, stream and
request of the previous client, and one missed would show or send that
client's data under the next one's token.

**Decision (Burhan's calls, F4).**
- **A switch reloads the page.** The new token is stored and the page is
  replaced by its own path and query, without its hash, so no `#chat=` id of
  the previous client is ever sent with the next client's token. A switch is
  held while a turn streams. Storage that will not keep the new token stops
  the reload and says so, rather than signing the tab out.
- **`GET /api/auth/me` is the page's only judge of access.** Any 403 makes the
  shell re-check it, one check at a time. `/me` refusing (401/403) ends the
  tab's sign-in, and the server's sentence is shown on the signed-out page; a
  role or workspace that changed reloads the page; otherwise the refusal was a
  role's, shown where the action was.
- **The page never computes the switchable set** and sends a workspace id only
  to `POST /api/auth/switch`. Doors follow the active role (`mayChange`,
  `isAdmin`), and the server refuses them anyway.

**Bounds, stated.**
- Each tab holds its own token (D-056): two tabs may sit in two clients, and
  nothing synchronises them.
- A dead token cannot list where else its person may go (`/me` refuses it), so
  lost access means signing in again.
- A reload costs a page load; TD-047's 304s keep it to revalidations.
```
